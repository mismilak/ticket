# سامانه فروش بلیط (قابل شخصی‌سازی و فروش به مشتری)

سایت بلیط‌فروشی شبیه ملوتیک: رویدادها، **فروش بر اساس صندلی** و **فروش تعدادی**، سالن **چندطبقه** (همکف، بالکن، ...)، ورود با پیامک (کاوه‌نگار)، درگاه‌های ملت / سامان کیش / زرین‌پال، و پنل مدیریت کامل.
ساخته‌شده با Laravel 11 (PHP 8.2+). همه فایل‌های فرانت (بوت‌استرپ RTL، آیکن‌ها، فونت وزیرمتن، QR) **لوکال** در `public/vendor` هستند و هیچ CDN خارجی لازم نیست.

## نصب

```bash
composer install --no-dev -o
cp .env.example .env          # APP_URL و دیتابیس را تنظیم کنید
php artisan key:generate
touch database/database.sqlite   # اگر از SQLite استفاده می‌کنید (برای MySQL مقادیر DB_* را در .env بگذارید)
php artisan migrate --seed
php artisan db:seed --class=DemoSeeder   # (اختیاری) داده نمونه با سالن دو طبقه
```

- ریشه وب‌سرور باید پوشه `public` باشد. پوشه‌های `storage`، `bootstrap/cache` و `public/uploads` باید قابل نوشتن باشند (تصاویر در `public/uploads` ذخیره می‌شوند).
- مدیر پیش‌فرض: موبایل `09120000000` و رمز `admin1234` (با `ADMIN_MOBILE` / `ADMIN_PASSWORD` در `.env` قبل از seed قابل تغییر است). ورود مدیر: `/admin/login` — **حتماً رمز را عوض کنید** (پنل ← کاربران).
- اجرای محلی: `php artisan serve`. تا وقتی API کاوه‌نگار تنظیم نشده باشد (و `APP_DEBUG=true`) کد OTP روی صفحه نمایش داده می‌شود.

## امکانات پنل مدیریت (`/admin`)

| بخش | توضیح |
|---|---|
| **تنظیمات** | نام سایت، لوگو، فاوآیکن، رنگ‌های قالب، CSS و کد `<head>` دلخواه، فوتر و شبکه‌های اجتماعی، مهلت پرداخت، کارمزد، کاوه‌نگار، درگاه‌ها |
| **مجوزهای فوتر** | اینماد، ساماندهی و هر نماد دیگر: آپلود تصویر + لینک، یا چسباندن کد HTML نماد |
| **صفحات** | درباره ما، قوانین، ... با لینک خودکار در فوتر |
| **اسلایدر / دسته‌بندی‌ها** | صفحه اصلی |
| **سالن‌ها و پلان صندلی** | طراح بصری: افزودن ردیف (با انحنا)، انتخاب و جابجایی گروهی، دسته‌بندی صندلی (VIP/طلایی/...) با رنگ، صحنه/متن/مستطیل، **چند طبقه** (مثلاً بالکن)، شماره‌گذاری، Undo |
| **رویدادها** | چند سانس (هر سانس موجودی صندلی و ظرفیت جدا)، تاریخ شمسی، انتخاب سالن، قیمت هر دسته صندلی، یا بلیط عمومی تعدادی با ظرفیت، گزارش فروش |
| **سفارش‌ها / کنترل بلیط** | جزئیات تراکنش، لغو، ثبت ورود با کد بلیط (جلوگیری از استفاده دوباره) |

## فروش صندلی و جلوگیری از فروش مضاعف
- با ساخت سفارش، صندلی‌ها به‌مدت `hold_minutes` رزرو می‌شوند؛ سفارش پرداخت‌نشده منقضی و صندلی آزاد می‌شود.
- جلوگیری از فروش دوباره در سطح دیتابیس با ایندکس یکتا (`order_items.lock_key`) انجام می‌شود؛ حتی در درخواست‌های همزمان یک صندلی دوبار فروخته نمی‌شود.

## درگاه‌ها و پیامک
تنظیم از پنل ← تنظیمات ← «درگاه‌های پرداخت» و «پیامک».
- **زرین‌پال** (API v4 + Sandbox)، **بانک ملت** (به‌پرداخت، SOAP با cURL؛ بدون نیاز به افزونه soap)، **سامان کیش** (SEP/OnlinePG با توکن)، و **درگاه آزمایشی داخلی** (فقط برای تست؛ در سایت واقعی خاموش کنید).
- کاوه‌نگار: `verify/lookup` با قالب (Template) شما؛ قالب کد تایید یک توکن `%token` دارد.
- آدرس بازگشت هر تراکنش خودکار ساخته می‌شود: `/payment/callback/{id}`. دامنه/IP سرور را در پنل بانک ثبت کنید.

> ⚠️ پیاده‌سازی درگاه‌ها و کاوه‌نگار بر اساس مستندات عمومی آن‌هاست؛ در محیط توسعه امکان اتصال واقعی به بانک‌ها نبود. جریان کامل خرید با درگاه آزمایشی و تست‌های خودکار (`php artisan test`) بررسی شده است. قبل از انتشار یک پرداخت واقعی کم‌مبلغ با هر درگاه تست کنید.

## ساختار کد
- `app/Services/OrderService.php` — رزرو، ظرفیت، قفل صندلی، پرداخت/آزادسازی
- `app/Payment/*` — هر درگاه یک کلاس (`start` / `verify`)؛ درگاه جدید را در `config/ticket.php` ثبت کنید
- `config/ticket.php` — تعریف همه تنظیمات قابل ویرایش از پنل
- `public/js/designer.js` و `public/js/seatmap.js` — طراح پلان و نقشه انتخاب صندلی
